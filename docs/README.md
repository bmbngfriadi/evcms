# EVCMS - Electric Vehicle Charging Management System

## Overview
EVCMS is a phase-1 internal application to monitor charging cycles for BYD M6 electric vehicles.

## Key Features
- Focus on Charging Cycle (Draft, Charging, Completed)
- No IoT integration required; data is manually inputted from the vehicle's dashboard.
- Calculates estimated battery energy added, estimated vehicle energy, and cost estimations based on Master Tariffs.
- Complete Audit Log for data integrity.
- Role-based permissions.
