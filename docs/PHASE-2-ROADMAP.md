# Phase 2 Roadmap

**Note: These features are not implemented in Phase 1.**

- **Vehicle Trip**: Tracking start and end of trips, mapping to driver.
- **Driver Management**: Dedicated Master for drivers.
- **Destination & Route**: Capturing start/end locations and GPS coordinates.
- **Trip History**: Detailed logs of every trip.
- **Vehicle Usage**: Daily utilization reports.
- **Charger Integration**: IoT connection to BYD Chargers or external OCPP chargers.
- **kWh Meter Integration**: Using actual electrical meter data instead of dashboard estimations.
- **Actual Charging Cost**: Based on grid meter readings.
